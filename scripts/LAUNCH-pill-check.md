# 아 맞다 약! 오픈 체크리스트

AWS에 처음 올릴 때 순서대로 확인해요.

## 1. 사이트 (S3 + CloudFront + WAF)
- [ ] S3 버킷 (서울 리전, 퍼블릭 차단 유지) + CloudFront 정액 무료 요금제 + OAC
- [ ] WAF 속도 제한: IP당 5분 1,000건, 차단
- [ ] CloudFront **압축(Compress objects automatically) 켜기**
- [ ] CloudFront **응답 헤더 정책**: HSTS, X-Content-Type-Options, Referrer-Policy(`strict-origin-when-cross-origin`), 프레임 차단
- [ ] CloudFront **오류 페이지**: 403 · 404 → `/404.html`, 응답 코드 404 (S3는 없는 파일에 403을 줌)
- [ ] 도메인 연결 (ACM 인증서 us-east-1)
- [ ] 올리기: `BUCKET=… DISTRIBUTION_ID=… ./scripts/deploy-pill-check.sh`
  - 버전(`?v=`, `sw.js` VERSION)은 스크립트가 자동으로 바꿔요. 손으로 안 바꿔도 돼요.
  - 캐시: html · sw.js · manifest는 매번 새로, css · js · 글꼴은 1년, 그림은 하루

## 6. 광고(애드센스) 켤 때
광고 자리는 안내 글 4개(도움말 · 식전식후 · 가족 · 잊지 않는 법)에 2개씩 만들어 두었고, 설정 전에는 숨겨져 있어요.
약 화면 · 개인정보처리방침 · 이용약관 · 404에는 광고를 넣지 않아요.

- [ ] 내 도메인 연결 후 애드센스 신청 (cloudfront.net · github.io 주소로는 신청 불가)
- [ ] 승인되면 루트에 `ads.txt` 만들기: `google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0`
- [ ] 애드센스에서 '디스플레이 광고' 단위 8개 만들기 → `js/ads.js` 의 `client`, `domain`, `slots` 채우기
- [ ] 애드센스 설정
  - 자동 광고: **끄기** (특히 앵커 광고 · 전면(비네트) 광고 끄기)
  - 차단 관리 → 민감한 카테고리: 도박, 성인, 점술, '빨리 부자 되기', 대출 등 차단
  - 의약품 · 건강기능식품 · 병원 광고도 차단 권장 (어르신이 사이트 추천으로 오해할 수 있음)
- [ ] 개인정보처리방침 6번(쿠키 · 분석 도구 · 광고)을 아래로 바꾸기 + 시행일 변경, 7일 전 공지
- [ ] 이용약관에 '광고' 항목 추가 + 시행일 변경
- [ ] 광고 수익은 소득이라 종합소득세 신고 대상 (금액 · 사업자등록 필요 여부는 세무서나 세무사에게 확인)

### 개인정보처리방침 6번 바꿀 글 (예시)
> **6. 광고와 쿠키**
> 서비스는 도움말 · 안내 글 페이지에만 구글 애드센스 광고를 보여 줘요. 약 화면에는 광고가 없어요.
> 구글은 광고를 보여 주고 부정 클릭을 막기 위해 쿠키 같은 브라우저 정보를 쓸 수 있어요. 서비스는 개인 맞춤 광고를 끄고(관심사에 맞춘 광고를 하지 않음) 광고를 보여 줘요.
> 적으신 약 · 먹은 기록 · 몸 상태는 광고에 쓰이지 않고, 구글로 보내지지 않아요.
> 쿠키를 원하지 않으면 브라우저 설정에서 쿠키를 막거나, 구글 광고 설정(adssettings.google.com)에서 바꿀 수 있어요.
> 서비스는 방문 분석 도구를 쓰지 않아요.

### 이용약관에 넣을 글 (예시)
> **광고**
> 안내 글 페이지에는 광고가 나올 수 있어요. 광고 내용은 광고하는 회사가 책임지며, 서비스가 추천하는 것이 아니에요.
> 약이나 건강식품 광고를 보시면 드시기 전에 꼭 의사 · 약사와 상의하세요.
