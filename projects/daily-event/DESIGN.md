# 소소한 일상의 이벤트 — 디자인 가이드

> 매일 아침 우편함에 도착하는 작은 초대장. 종이·우표·소인의 손맛은 살리되, 화면은 단정하고 읽기 쉽게.
> 대상: **일반**(스마트폰에 익숙한 10~30대) · 운영: **실서비스**. 코드 구조는 [`FRONTEND.md`](FRONTEND.md).

## 1. 원칙
| 원칙 | 이렇게 한다 |
|---|---|
| 하루 한 통 | 화면마다 눌러야 할 큰 버튼은 하나 (초대장 열기 → 도전할게요 → 완료 소인 찍기) |
| 초대장은 주인공 | 꾸밈(우표 테두리, 소인, 봉투)은 초대장 카드와 봉투에만. 나머지 UI는 담백하게 |
| 부담 주지 않기 | '미션', '실패' 대신 '초대장', '도전'. 완료하지 않은 날도 달력에서 탓하지 않음 |
| 색 + 글자 + 모양 | 상태를 색만으로 알리지 않음 (완료 = 소인 모양 + "완료" 글자, 오늘 = 굵은 테두리 + 범례) |
| 모바일 한 손 | 375~430px 기준. PC도 같은 화면을 가운데 정렬 |

## 2. 색
역할 5개(바탕·표면·글자·주요·강조)로 시작하고, 나머지는 이 5개의 밝기 변형만 쓴다 (CSS_GUIDE 2-2).

| 토큰 | 값 | 쓰임 | 배경 대비 |
|---|---|---|---|
| `--color-bg` | `#f7f3ea` | 페이지 배경 (편지지 크림색) | — |
| `--color-surface` | `#fffdf8` | 카드, 초대장, 입력칸 바탕 | — |
| `--color-text` | `#23201b` | 본문 | 약 14.7:1 |
| `--color-text-sub` | `#55504a` | 보조 글자 (날짜, 설명, 라벨) — 글자색 밝기 변형 | 약 7.2:1 |
| `--color-primary` | 유형별 (아래 표) | 주요 버튼, 현재 탭, 선택된 카드, 링크 | 7:1 이상 |
| `--color-accent` | `#98211a` | 소인 빨강: 완료 소인, 포커스 테두리, 주의 | 약 7.4:1 |
| `--color-line` | `#8c857a` | 버튼·입력칸 테두리 (글자 밝기 변형) | 약 3.3:1 (UI 요소 3:1 충족) |
| `--color-divider` | 글자 12% 섞음 | 카드 테두리, 구분선 (장식) | — |
| `--color-soft` | 주요 12% 섞음 | 선택된 카드·태그 바탕 | — |
| `--color-on-primary` | `#ffffff` | 주요 버튼 위 글자 | 7.9:1 이상 |

### 유형별 주요 색
`html[data-type="student|worker|free"]`에서 **`--color-primary` 값만** 바꾼다. 새 토큰을 만들지 않는다.

| 유형 | 값 | 이름 | 크림 배경 대비 | 흰 글자 대비 |
|---|---|---|---|---|
| 학생 `student` | `#0e5a60` | 청록 잉크 | 약 7.2:1 | 약 7.9:1 |
| 직장인 `worker` | `#24407a` | 남색 잉크 | 약 9.1:1 | 약 10:1 |
| 자유인 `free` | `#5a3d8a` | 보라 잉크 | 약 7.7:1 | 약 8.5:1 |
| 유형 고르기 전 | `#24407a` | 남색 (기본값) | 약 9.1:1 | 약 10:1 |

- 강조색은 **유형 색 1개 + 소인 빨강 1개**만 쓴다
- `--color-soft` 바탕 위 글자는 `--color-text`로 쓴다 (주요 색 글자는 6.4:1까지 떨어짐)
- 섞은 색(`--color-soft`, `--color-divider`)은 `body`에서 `color-mix()`로 계산해야 유형 색이 반영된다
- 유형 고르기 화면에서는 고르는 순간 `data-type`이 바뀌어 화면 색을 미리 보여 준다
- 다크 모드는 MVP에서 하지 않는다

| 이름 | 값 | 이름 | 값 |
|---|---|---|---|
| 봉투 | `#efe6d2` | 봉투 덮개 | `#e8dcc2` |
| 봉투 선 | `#c9b998` | 봉인 씰 | `#98211a` |
| 씰 안 무늬 | `#f7e9e4` | 우표 그림 | 유형 색 |

## 3. 글자
- 본문 글꼴: `Pretendard → Noto Sans KR → Apple SD Gothic Neo → Malgun Gothic` (Pretendard CDN)
- 꾸밈 글꼴: **고운바탕(Gowun Batang) 700** 1개만 (Google Fonts). 화면 제목, 초대장 제목, 달력 상세 제목에만 쓴다. 버튼·본문·숫자에는 쓰지 않는다
- 숫자(날짜, 완료 횟수, 30자 카운터): `font-variant-numeric: tabular-nums`

| 토큰 | 크기 | 쓰임 |
|---|---|---|
| `--fs-sm` | 0.9375rem (15px) | 보조 정보 (태그, 카운터, 달력 요일, 안내) |
| `--fs-md` | 1.0625rem (17px) | 본문 기본, 입력칸, 헤더 사이트 이름 |
| `--fs-lg` | 1.1875rem (19px) | 버튼, 카드 제목 |
| `--fs-xl` | 1.5rem (24px) | 초대장 이벤트 제목 (고운바탕) |
| `--fs-xxl` | clamp(1.625rem, 6vw, 2rem) | 화면 제목 (고운바탕) |

- 굵기: 본문 400, 라벨·버튼 700
- 행간 1.6 (제목 1.35), `word-break: keep-all`
- 입력칸 글자는 16px 이상 (아이폰 확대 방지)

## 4. 간격 · 모양
| 토큰 | 값 | 토큰 | 값 |
|---|---|---|---|
| `--space-xs` | 0.5rem | `--radius` | 0.75rem (버튼, 입력칸, 작은 카드) |
| `--space-sm` | 0.75rem | `--radius-lg` | 1.25rem (유형 카드, 우편함, 달력) |
| `--space-md` | 1.25rem | `--radius-pill` | 태그, 유형 버튼 |
| `--space-lg` | 2rem | `--border-w` | 0.125rem (2px) |
| `--space-xl` | 3rem | `--touch` | 3.25rem (52px, 버튼 높이) |
| `--page-pad` | clamp(1rem, 5vw, 1.25rem) | `--content-max` | 30rem (PC에서도 이 폭으로 가운데 정렬) |

- 그림자: 초대장 카드에만 아주 옅게 (`drop-shadow`, 글자색 10%). 나머지는 테두리로 구분
- 모바일 먼저 → 768px·1024px에서도 레이아웃은 그대로, 위아래 여백만 늘어남

## 5. 컴포넌트
### 헤더 · 탭
- 헤더: 왼쪽 사이트 이름(`h1`, 봉투 아이콘), 오른쪽 **[✎ 유형 이름]** 알약 버튼 (낭독기: "직장인 · 내 하루 바꾸기")
- 탭 2개: 오늘의 초대장 / 이벤트 달력. 현재 탭은 `aria-current="page"` + 주요 색 글자 + 아래 3px 막대

### 버튼
| 종류 | 클래스 | 쓰임 |
|---|---|---|
| 주요 | `.btn--primary` | 화면당 하나 (시작하기, 초대장 열기, 도전할게요, 완료 소인 찍기) |
| 기본 | `.btn` | 보조 동작 (다른 초대장 받기, 달력에서 보기, 링크 복사, 소인 취소하기) |
| 아이콘 | `.btn--icon` | 닫기, 이전 달·다음 달 (`aria-label` 필수, 44px) |

- 크기: 52px, 가로 꽉 채움(`.btn--block`)이 기본. 아이콘 + 글자
- 쓸 수 없는 상태(교체 0회): `aria-disabled="true"` + 흐린 글자·테두리 + 버튼 아래 이유 문구

### 유형 선택 카드
- `fieldset` + `legend` 안에 라디오 카드 3개를 세로로 쌓음
- 카드: 라디오 → 유형 그림(52px 원, 유형 색) → 이름(굵게) + 시간대 3개(보조 글자). 자유인은 이름 아래 "잠시 쉬어 가는 중"
- 선택됨(`:has(:checked)`): 그 유형 색 2px 테두리 + 연한 바탕 + 오른쪽 위 ✓
- 아무것도 안 고르고 [시작하기]를 누르면 `role="alert"` 안내

### 우편함 · 봉투
- 표면색 상자 안에 "새 우편" 배지 + "도착한 초대장 1통" → 봉투 그림 → "발신: 일상 우체국 · 수신: 오늘의 나"
- 봉투: 크림 몸통 + 덮개 + 가운데 빨간 하트 봉인 + 오른쪽 위 우표(유형 색 그림) + 소인 물결
- 오늘 이미 열었으면 봉투 대신 초대장 카드를 바로 보여 줌

### 초대장 카드
- 표면색 카드 + **우표처럼 톱니 모양 테두리** (`radial-gradient` 반복 배경, 안쪽 종이는 표면색)
- 위부터: "오늘의 초대장 · 제 N호" 라벨(유형 색) → 이벤트 제목(고운바탕) → 설명 → 태그 3개(시간대 · 분류 · 난이도) → 점선 절취선 + 발신·수신
- 오른쪽 위 작은 우표(4° 기울임)에 분류 그림 + 분류 이름 (길 바꾸기 = 갈림길, 먹어보기 = 그릇, 관찰하기 = 눈, 말 걸기 = 말풍선, 기록하기 = 연필)
- 초대장이 열리거나 바뀌면 제목으로 포커스가 가고, 상태 영역에 새 제목을 알림

### 태그
- 알약 모양, `--color-soft` 바탕 + 글자색, `--fs-sm`
- 난이도 '살짝 용기'만 앞에 작은 별 아이콘 (색만으로 구분하지 않음)

### 소인 (완료 표시)
- 지름 8rem 원, 소인 빨강 이중 테두리(바깥 3px, 안쪽 1px) + "일상 우체국" / 날짜 `11.24` / "완료"
- -8° 기울이고 `opacity: 0.92`
- 찍기 전 자리: 점선 원 + "소인 자리"
- [완료 소인 찍기]는 `aria-pressed`. 찍은 뒤에는 기본 버튼 [소인 취소하기]

### 한 줄 기록
- `label` 연결된 입력칸 1개, 최대 30자, 쓰는 대로 저장. 오른쪽 아래 `쓰는 대로 저장돼요 · 0 / 30자` (`aria-describedby`)
- 30자가 되면 카운터를 소인 빨강 + "30자까지 쓸 수 있어요"

### 이벤트 달력
- `table` + `caption`(화면에서 숨김), 요일 `th scope="col"`
- 날짜 칸: 최대 44px 원형 버튼(320px 폭에서는 칸에 맞춰 줄어듦). `aria-label="11월 20일, 완료"`
  - 완료: 소인 빨강 2px 원 + 빨강 굵은 숫자, -8° 기울임
  - 오늘: 주요 색 3px 테두리
  - 선택됨: `aria-pressed="true"` + `--color-soft` 바탕
- 달력 아래 범례(완료 소인 / 오늘)
- 달력 위: 요약 2칸(`dl`) — 완료한 날 / 가장 많이 한 분류
- 달력 아래: 선택한 날짜 상세(제목 · 이벤트 · 한 줄 기록) → 기록 위치 안내
- 다음 달 버튼은 이번 달에서 `disabled`

### 안내 · 빈 상태
| 종류 | 모양 | 예 |
|---|---|---|
| 기본 `.notice` | ⓘ 아이콘 + 보조 글자 | 기록은 이 기기 브라우저에만 저장돼요 |
| 경고 `.notice--warn` | 소인 빨강 2px 테두리 + ⓘ | 이 브라우저에서는 기록이 저장되지 않아요 |
| 빈 상태 `.empty` | 점선 그림 + 제목 + 버튼 1개 | 이번 달 첫 소인을 찍어 보세요 |

### PC 휴대폰 안내 카드
- 탭 아래, 2px 글자색 테두리 카드. 왼쪽 QR(7rem, 주소가 정해진 뒤), 오른쪽 "휴대폰으로 이어서 하기" + 설명 + [링크 복사]
- 오른쪽 위 닫기 버튼(44px, `aria-label="휴대폰 안내 닫기"`). 닫으면 다시 보이지 않음
- 복사 결과는 `role="status"`. 복사가 안 되면 주소 입력칸을 선택된 채로 보여 줌
- `(min-width: 1024px), (pointer: fine)`에서만 보임

### 광고 자리
- 기존 사이트와 같은 마크업: `<aside class="ad" aria-label="광고">` + `.ad__label` "광고" + `.ad__box`
- `.ad__box`는 `min-height: 6.25rem`(100px)을 미리 잡음. 광고 설정이 비어 있으면 자리째 그리지 않음
- 화면 콘텐츠 아래, 자주 묻는 질문 위 한 곳. 위에 구분선

### 자주 묻는 질문 · 푸터
- `details` 8개, 오른쪽 `+ / −`
- 푸터: 표면색, 위 테두리. 개인정보 처리방침 링크 + `© 2026 소소한 일상의 이벤트`

## 6. 그림
- **봉투**: `viewBox 0 0 300 210`. 몸통(6,14,288×190) → 접힌 선 → 덮개(꼭짓점 150,122) + 씰(r 27) → 우표(226,26,52×62) → 소인 물결
- **분류 그림 5종 · 유형 그림 3종 · UI 아이콘**: `index.html` 위쪽 아이콘 모음(`<symbol>`)
- **공유 이미지** `images/og-image.png` 1200×630, **앱 아이콘** 180·192·512px, **파비콘** SVG

## 7. 아이콘
- 24 × 24 격자, 선 굵기 2~2.6, 둥근 끝, 채우기 없음 (별만 채움)
- `currentColor`로 글자색을 따름. 화면에는 항상 글자와 함께 (아이콘만 있는 버튼은 `aria-label`)

## 8. 움직임
| 대상 | 시간 | 방식 |
|---|---|---|
| 봉투 열기 | 0.6초 | 덮개 `scaleY(-1)` (윗변 기준으로 젖혀짐) + 씰 사라짐, 0.65초 뒤 초대장 |
| 초대장 나옴 · 바뀜 | 0.5초 | 아래에서 위로 `translateY` + 페이드 |
| 소인 찍기 | 0.35초 | `scale(1.4) → 1` + 기울기, 한 번만 |
| 탭 전환 | 없음 | 바로 바뀜 |

- 깜빡임·자동 반복 금지. 그 밖의 `transition`은 0.15초 이하 색 변화만
- `prefers-reduced-motion`이면 봉투 연출을 건너뛰고, 나머지는 0.15초 페이드

## 9. 문구
- 해요체, 짧게, 쉬운 말. 사용자를 재촉하거나 탓하지 않는다
- 이벤트 제목은 짧은 명사형·"~하기", 설명은 한 문장

| 상황 | 이렇게 | 이렇게 쓰지 않기 |
|---|---|---|
| 메인 | 오늘은 어제와 딱 하나만 다르게 | 오늘의 미션을 확인하세요 |
| 도착 | 도착한 초대장 1통 | 새 미션 1개 |
| 수락 | 도전할게요 | 미션 수락 |
| 교체 | 다른 초대장 받기 (오늘 1회 남음) | 리롤 |
| 교체 소진 | 오늘의 초대장은 이걸로 확정이에요 | 교체 횟수를 모두 사용했습니다 |
| 완료 | 완료 소인 찍기 | 미션 완료 처리 |
| 안 한 날 | 이날은 소인이 없어요 / 이날은 기록이 없어요 | 미완료 / 실패 |
| 빈 달력 | 이번 달 첫 소인을 찍어 보세요 | 기록 없음 |
| 오류 | 초대장이 아직 도착하지 않았어요 | 데이터 로드 오류 |

## 10. 접근성
- 텍스트 대비 7:1 이상 (유형 색 3가지 모두), 테두리·UI 요소 3:1 이상
