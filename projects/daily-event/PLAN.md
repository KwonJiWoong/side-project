# 소소한 일상의 이벤트 (기획)

> 똑같은 하루에 작은 변화 하나. 매일 "오늘의 이벤트 초대장"을 열고, 평소와 조금 다른 행동 1가지를 해본다.

## 개요
- **유형**: 대상 일반 · 운영 실서비스 (메인 포트폴리오 카드 없음)
- **타깃**: 매일 같은 길, 같은 메뉴, 같은 루틴이 반복된다고 느끼는 사람
- **메인 기기**: **모바일**. 기록이 서버 없이 이 기기 브라우저(localStorage)에만 저장돼 PC와 휴대폰이 기록을 공유할 수 없으므로, 매일 들고 다니는 휴대폰을 기준으로 만든다
- **사용 상황**: 아침에 집을 나서기 전 1번 열어보고 → 하루 중 그 이벤트 실천
- **진입 문구**: "오늘은 어제와 딱 하나만 다르게"
- **기술**: 이 사이트만 **Vite + React**로 만든다 (저장소의 다른 사이트는 Vanilla JS). 빌드한 `dist/`를 자체 도메인에 올린다
- **도파민 메뉴판과 차이**: 숏폼 대체(쉬는 시간 활동)가 아니라, **일상 루틴 자체에 변화를 주는 것**이 목적

## 사용자 유형
| 유형 | 표시 이름 | 일상 시간대 |
|---|---|---|
| 학생 | 학생 | 등굣길 · 쉬는 시간 · 하굣길 |
| 직장인 | 직장인 | 출근길 · 점심시간 · 퇴근길 |
| 백수/백조 | 자유인 *(잠시 쉬어 가는 중)* | 아침 산책 · 낮 시간 · 저녁 |

- 처음 1회 고른 뒤 저장, 헤더의 유형 버튼으로 언제든 바꿈
- 소인을 아직 안 찍은 날 유형을 바꾸면 그날 초대장도 새 유형으로 다시 옴

## 화면 흐름
1. **유형 고르기** (첫 방문만): 라디오 카드 3개 → [시작하기]
2. **오늘의 초대장 탭**: 오늘 날짜 + 봉인된 봉투 → [초대장 열기]
3. 봉투가 열리며 이벤트 1개: [도전할게요] / [다른 초대장 받기 (오늘 1회)]
4. 도전 중: [완료 소인 찍기] + 한 줄 기록(선택, 30자, 쓰는 대로 저장) → [달력에서 보기]
5. **이벤트 달력 탭**: 월간 달력에 소인, 날짜를 누르면 그날 이벤트·기록

## 핵심 규칙
- **하루 1개 고정**: 날짜 + 유형으로 정해지는 값으로 고름 → 같은 날 다시 열어도 같은 초대장. 연 순간 기록에 저장
- **교체 1회**: 뽑기 놀이가 되지 않도록 하루 1번만
- **중복 방지**: 최근 7일에 받은(바꾸기 전 포함) 초대장은 제외
- **유형별 분기**: 유형 전용 20개 + 공통 15개
- **날짜 바뀜**: 1분마다, 화면으로 돌아올 때마다 날짜를 다시 확인해 자정 뒤 새 초대장

## 콘텐츠
- `public/data/events.json` (유형별 20개 + 공통 15개, 총 75개)
- 항목: `id, types[], slot, category, title, desc, level`
- **카테고리**: 길 바꾸기 · 먹어보기 · 관찰하기 · 말 걸기 · 기록하기
- **작성 기준**: 돈이 거의 들지 않음 · 평소 일정에 5~10분 · 밝은 큰길 위주로 안전하게 · 길 바꾸기는 "5분 일찍 출발" · 한 문장 설명

## 기기와 화면 크기
- **모바일 우선**: 375~430px 기준
- **태블릿·PC**: 모바일 화면을 `max-width: 30rem` 가운데 정렬
- **PC → 휴대폰 안내 카드** (PC에서만): QR(도메인 연결 뒤) + [링크 복사]. 닫으면 다시 안 보임. 카카오톡 공유는 넣지 않음
- **기록 위치 안내**: 달력 아래 "기록은 이 기기 브라우저에만 저장돼요"
- **홈 화면에 추가**: `manifest.webmanifest` + 아이콘, 방법은 자주 묻는 질문에

## 예외 상태
- **초대장 목록 불러오기 실패**: "초대장이 아직 도착하지 않았어요" + [다시 시도]
- **교체 소진**: 버튼 `aria-disabled` + "오늘의 초대장은 이걸로 확정이에요"
- **빈 달력**: "이번 달 첫 소인을 찍어 보세요" + [오늘의 초대장 보기]
- **저장 불가**: 초대장은 동작, "기록이 저장되지 않아요" 안내
- **링크 복사 실패**: 주소 입력칸을 선택된 채로 보여 주고 직접 복사 안내
- **자바스크립트 꺼짐**: `noscript` 안내
