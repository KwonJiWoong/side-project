# 자라는 시간 — 디자인 가이드

> 흙과 새싹처럼 차분하게. 폰을 내려놓는 동안 방해하지 않고, 돌아왔을 때 탓하지 않는다.

## 1. 원칙
| 원칙 | 이렇게 한다 |
|---|---|
| 한 화면 한 목적 | 시작 → 진행 → 결과 → 정원. 화면마다 눌러야 할 큰 버튼은 하나 |
| 진행 중엔 조용히 | 어두운 배경, 움직임 최소, 메뉴·푸터 숨김. 화면은 켜져 있어도 눈에 띄지 않게 |
| 탓하지 않기 | ‘실패’ 대신 ‘시들었어요’. 시든 식물도 정원에 남기고, 버틴 시간은 모은 시간에 넣음 |
| 색 + 글자 + 아이콘 | 상태를 색만으로 알리지 않음 (예: ✓ 꽃 피움 / ⚠ 새싹에서 시듦) |
| 누구나 쉽게 | 20~30대가 주 사용자지만, 저장소 공통 원칙(큰 글자·높은 대비·큰 터치 영역)을 그대로 지킴 |

| `--color-text` | `#1e2619` | 본문 | 약 14:1 |

|---|---|---|---|
| `--color-bg` | `#0d120d` | 배경 | — |

## 3. 글자
- 글꼴: `Pretendard → Noto Sans KR → Apple SD Gothic Neo → Malgun Gothic` (따로 불러오지 않고 기기 글꼴 사용)
- 숫자(남은 시간·통계): 숫자 폭이 일정한 글꼴 + `font-variant-numeric: tabular-nums` → 1초마다 흔들리지 않게

| 토큰 | 크기 | 쓰임 |
|---|---|---|
| `--fs-sm` | 1rem (16px) | 보조 정보 (날짜, 상태 글자) |
| `--fs-md` | 1.125rem (18px) | 본문 기본 |
| `--fs-lg` | 1.25rem (20px) | 버튼, 카드 제목 |
| `--fs-xl` | 1.5rem | 대화 상자 제목, 통계 숫자 |
| `--fs-xxl` | clamp 1.625~2.125rem | 화면 제목 |
| 남은 시간 | clamp 3.5~5rem | 진행 화면 시계 |

- 굵기: 본문 400, 라벨·버튼 700, 제목 800
- 행간 1.6, `word-break: keep-all`
- ‘글자 크게’ 버튼: 루트 글자 크기를 118.75%로 (본문 약 21px)

## 4. 간격 · 모양
| 토큰 | 값 | 토큰 | 값 |
|---|---|---|---|
| `--space-xs` | 0.5rem | `--radius` | 0.75rem (버튼 안 요소, 작은 카드) |
| `--space-sm` | 0.75rem | `--radius-lg` | 1.25rem (큰 카드, 화단, 대화 상자) |
| `--space-md` | 1.25rem | `--radius-pill` | 버튼 (완전히 둥글게) |
| `--space-lg` | 2rem | `--border-w` | 0.125rem (2px) |
| `--space-xl` | 3rem | `--touch` | 3.25rem (52px, 터치 최소 높이) |

- 내용 폭 최대 46rem, 가운데 정렬
- 모바일 먼저 → 768px(시간 4칸, 식물 4칸) → 1024px

## 5. 컴포넌트
### 버튼
| 종류 | 클래스 | 쓰임 |
|---|---|---|
| 주요 | `.btn--primary` | 화면에서 가장 중요한 동작 하나 (시작하기, 정원에 심기, 이어서 하기) |
| 기본 | `.btn` | 보조 동작 (다시 도전, 닫기, 계속하기) |
| 투명 | `.btn--ghost` | 진행 화면 ‘그만두기’ (눈에 덜 띄게) |
| 위험 테두리 | `.btn--danger` | 되돌릴 수 없는 동작으로 가는 버튼 (정원 비우기) |
| 위험 채움 | `.btn--danger-fill` | 확인 창에서 위험 동작 확정 |

- 크기: 기본 52px, `.btn--lg` 60px, `.btn--sm`은 설정 영역에만
- 아이콘은 항상 글자와 함께 (`아이콘 + 글자`)

### 선택 카드
- **시간**: 라디오 + 큰 숫자(`10`) + 작은 단위(`분`). 선택되면 초록 채움
- **식물**: 화분 그림 + 이름 + 상태 글자. 잠긴 식물은 흑백·흐리게 + 🔒 아이콘 + "1시간 모으면 열려요"
- 키보드 포커스는 카드 바깥에 주황 3px 테두리

### 안내문 (`.notice`)
| 종류 | 모양 | 예 |
|---|---|---|
| 기본 | 회색 글자, 테두리 | 브라우저 데이터를 지우면 정원이 사라져요 |
| `--warn` | 주황 글자·테두리 + ⚠ | 다른 화면에 3초 다녀왔어요 |
| `--good` | 초록 바탕 | 새 식물 ‘튤립’이 열렸어요 |

### 대화 상자 (`<dialog>`)
- 제목 1줄 + 설명 + 세로로 쌓은 큰 버튼 2개
- 되돌릴 수 없는 동작(그만두기, 정원 비우기): **처음 포커스는 ‘취소’ 쪽**
- 꼭 골라야 하는 창(자리를 비웠어요): Esc로 닫히지 않음, 안전한 선택(이어서 하기)이 주요 버튼

### 진행 게이지
- 지름 최대 20rem 원, 선 굵기 10, 12시 방향부터 시계 방향으로 채움
- 자라는 중: 초록 / 꽃 핀 뒤 보너스: 초록은 흐리게, 그 위에 **주황 링**이 30분 동안 채워짐
- 원 안에 화분, 아래에 단계 글자(씨앗을 심었어요 → 꽃이 피었어요)

### 주간 화단
- 한 주(월~일)에 화단 하나. 제목: 이번 주 화단 / 지난주 화단 / 11월 9일 ~ 11월 15일 화단
- 초록 바탕 상자 안에 식물을 격자로, 식물 아래 흙 띠가 이어져 한 줄 밭처럼 보이게
- 각 식물: 그림 + 이름 + 상태(✓ 꽃 피움 / ⚠ 새싹에서 시듦) + 시간·날짜
- 방금 심은 식물은 초록 테두리 + 아래에서 올라오는 등장

### 화단 사진 (공유용 이미지)
- 1080 × 1350 (인스타그램 4:5), 종이색 배경
- 위: 서비스 이름 · 화단 제목 · 통계 3칸 / 가운데: 흙 띠 위에 식물 최대 12그루(4 × 3) / 아래: 날짜 한 줄
- 심은 만큼만 줄을 그리고 가운데로 모음

## 6. 식물 일러스트
- 캔버스 `viewBox 0 0 120 160`. 화분 윗면 y=113, 줄기 시작 (60,114), 꽃 중심 (60,40)
- 땅에 심은 모습(화단)은 화분을 빼고 `viewBox 0 6 120 114`
- 단계별로 보이는 부분

| 단계 | 줄기 | 새싹 잎 (y≈100) | 큰 잎 (y≈70~84) | 꽃 |
|---|---|---|---|---|
| 0 씨앗 | — | — | — | — (흙 위 씨앗만) |
| 1 새싹 | 28% | ○ | — | — |
| 2 잎 | 80% | ○ | ○ | — |
| 3 꽃 | 100% | ○ | ○ | ○ |

- 시든 모습: 몸통을 화분 기준 -16° 기울이고 누렇게(채도↓·세피아)
- 식물 8종과 해금 기준 (모은 시간)

| 데이지 | 튤립 | 해바라기 | 선인장 | 라벤더 | 장미 | 수국 | 무궁화 |
|---|---|---|---|---|---|---|---|
| 처음부터 | 1시간 | 3시간 | 5시간 | 8시간 | 12시간 | 18시간 | 25시간 |

- 새 식물 추가: `js/plants.js`의 `SPECIES`에 이름·해금 시간, `PARTS`에 꽃(필요하면 새싹·잎·줄기 색) 모양을 넣는다. 색은 CSS 변수 없이 색값으로 (이미지 저장 때도 보이게)

## 7. 아이콘
- 24 × 24 격자, 선 굵기 2~2.2, 둥근 끝. 채우기 없이 선으로 (재생 버튼만 채움)
- `currentColor`로 글자색을 따름. 화면에는 항상 글자와 함께 둠

## 8. 움직임
| 대상 | 시간 | 방식 |
|---|---|---|
| 줄기 자람 | 1.2초 | `stroke-dashoffset` |
| 잎·꽃 나옴 | 0.8초 (0.5초 뒤) | `transform: scale` 살짝 튕기며 |
| 시듦 | 1초 | 회전 + 색 빠짐 |
| 게이지 | 1초, 일정하게 | `stroke-dashoffset` |
| 성공 원 퍼짐 | 1.4초 × 2번 | 결과 화면에서만 |

- 깜빡임·자동 반복 금지. `prefers-reduced-motion`이면 모든 움직임을 즉시 끝냄

## 9. 문구
- 해요체, 짧게, 쉬운 말. 사용자를 탓하지 않는다
- 숫자는 단위와 함께: `25분`, `1시간 20분`, `3그루`, `2일`

| 상황 | 이렇게 | 이렇게 쓰지 않기 |
|---|---|---|
| 끝남 | 꽃이 피었어요 | 타이머 종료 |
| 실패 | 시들었어요. 8분 버텼어요 | 실패했습니다 |
| 잠깐 나감 | 다른 화면에 3초 다녀왔어요 | 이탈이 감지되었습니다 |
| 급한 일 | 자리를 비웠어요 / 급한 일이었어요, 이어서 하기 | 일시정지 |
| 잠김 | 1시간 모으면 열려요 | 잠금 해제 조건 미달 |
| 입력 오류 | 1부터 180 사이의 숫자(분)를 넣어 주세요. 예: 30 | 잘못된 입력 |

## 10. 접근성
- 텍스트 대비 7:1 이상 (밝은·어두운 화면 모두)
- 터치 영역 52px 이상, 버튼 사이 8px 이상
- 키보드 포커스: 주황 3px 테두리 + 3px 띄움
- 남은 시간은 화면에서 매초 바뀌지만, 스크린리더에는 **1분 단위·단계 변화만** 알림 (`aria-live="polite"`)
- 화면이 바뀌면 그 화면 제목으로 포커스 이동
- 글자 크게 + 320px 폭에서도 가로 스크롤 없음
