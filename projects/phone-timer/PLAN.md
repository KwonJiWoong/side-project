# 자라는 시간 — 폰 내려놓기 타이머 (기획)

> 폰을 안 보는 동안 화분이 자라고, 다른 앱으로 넘어가면 시든다.

## 개요
- **타깃**: 공부·업무 중에 폰을 덜 보고 싶은 20~30대 (자기 전은 제외 — 화면을 켜둔 채로는 잘 수 없음)
- **사용 상황**: 타이머를 켜고 → 화면 켜둔 채 폰을 엎어두기 → 시간이 끝나면 확인
- **주 플랫폼**: 모바일 우선 (PC는 보조)
- **차별점**: Forest 같은 앱과 달리 **설치 없이 웹에서 바로 사용**
- **운영**: 실서비스 (포트폴리오 메인 카드 없음)
- **디자인**: 흙·초록 계열의 차분한 톤, 진행 화면은 어두운 배경 → 자세한 규칙은 [DESIGN.md](DESIGN.md)

## 화면 흐름
1. **시작 화면**: 시간 선택(10 / 25 / 50분, 직접 입력) + 식물 선택(해금된 것만) → [시작]
2. **안내 오버레이**: "화면을 켜둔 채 폰을 엎어두세요" (최초 1회 + 설정에서 다시 보기)
3. **진행 화면**: 원형 게이지로 남은 시간, 식물이 단계별로 성장 (씨앗 → 새싹 → 잎 → 꽃)
   - 꽃이 핀 뒤: **보너스 시간** (최대 30분) + [다 했어요, 정원에 심기]
4. **결과 화면**
   - 성공: "꽃이 피었어요" + [정원에 심기] + **[자랑하기]**(오늘 핀 꽃 카드) + 새 배지를 받았으면 안내
   - 실패: "시들었어요 (N분 버팀)" + **버틴 단계까지의 식물을 정원에 기록** (부분 보상) + [다시 도전]
5. **내 정원**: **주간 화단**(월요일마다 새 화단) + 모은 시간·이번 주 성공 일수·심은 식물 수 + 다음 식물까지 남은 시간 + **배지 8종** + [화단 사진 저장하기]

## 핵심 기능 (MVP)
- **화면 유지**: Wake Lock API로 진행 중 화면 꺼짐 방지
  - 미지원 브라우저는 "화면 자동 꺼짐 시간을 늘려주세요" 안내
- **이탈 감지**: Page Visibility API(`visibilitychange`)
  - 다른 앱 전환이나 화면 끄기 = 이탈
  - 10초 유예 — 유예 안에 돌아오면 경고만, 넘기면 실패
  - **급한 일 이어하기**: 10초~5분 사이에 돌아오면 "자리를 비웠어요" 창 → 한 번만 이어서 할 수 있음 (비운 시간은 빼고 계산). 두 번째부터, 또는 5분 넘게 나가면 실패
- **시간 계산**: 시작 시각 저장 후 `Date.now()` 차이로 계산 (백그라운드 지연 대응)
- **부분 보상**: 실패해도 버틴 시간에 해당하는 성장 단계로 기록 — 정원에는 **시든 모습 그대로** 남김 (성공과 구분)
- **보너스 성장**: 끝난 뒤에도 폰을 그대로 두면 최대 30분까지 시간이 더 쌓임 → 늦게 확인해도 손해가 아니라 보상. 보너스 중 화면을 나가면 거기까지 인정하고 마무리
- **식물 해금**: 8종 — 데이지(기본) · 튤립 1시간 · 해바라기 3시간 · 선인장 5시간 · 라벤더 8시간 · 장미 12시간 · 수국 18시간 · 무궁화 25시간
- **저장**: localStorage (정원, 누적 시간, 해금 상태, 설정)
- **종료 연출**: 화면 애니메이션 + 효과음(Web Audio 차임) + 안드로이드 진동
  - 아이폰 무음 모드: `navigator.audioSession.type = 'playback'`으로 울리게 (iOS 17 이상), 2초 뒤 원래대로
- **홈 화면에 추가**: manifest + 아이콘, 설정에 [홈 화면에 추가하기] 안내 (안드로이드는 바로 추가 버튼). 아이폰 홈 화면 앱은 iOS 18.4 이상에서 화면 켜짐 유지
- **배터리 안내**: 50분 이상 고르면 "충전기를 꽂아 두면 마음 편히" 안내

## 예외 상태
- **빈 정원**: "아직 심은 식물이 없어요" + [첫 타이머 시작] 버튼
- **localStorage 사용 불가**(시크릿 모드 등): 타이머는 동작하고, "기록이 저장되지 않아요" 안내
- **데이터 유실 안내**: 정원 화면에 "브라우저 데이터를 지우면 정원이 사라져요" 문구

## 자랑하기 (2026-11-24 추가)
- **자랑하기 카드:** 꽃을 피웠을 때만 결과 화면에 [자랑하기]. 1080×1920(인스타 스토리 9:16) 카드에 핀 꽃 · "N분 동안 폰을 내려놓고 OO를 피웠어요" · 보너스 · 모은 시간 · 이번 주 성공 · 배지(이번에 받은 것 먼저, 최대 4개). 휴대폰은 공유 창, PC는 파일 저장
- **배지 8종:** 첫 꽃 · 다시 피움(시든 다음 타이머에서 꽃) · 한 번에 50분 · 보너스 30분 · 한 주 3일 · 한 주 5일 · 10시간 모음 · 여덟 가지 꽃. 기록에서 매번 다시 계산해서 따로 저장하지 않음. 받으면 결과 화면에 "새 배지 ‘OO’를 받았어요" 안내, 정원에 받은 날짜 표시
- **지키는 것:** 진행 중에는 자랑하기 없음, 시든 결과는 카드를 만들지 않음, 확인용 `?fast` 기록은 배지·카드에서 뺌, 남과 비교하는 문구 없음
- **나중에:** 내 정원 링크(기록을 링크에 담아 읽기 전용 정원), 도전장 링크, 주간 화단 완성 카드. 친구와 같이 키우기·랭킹은 서버가 필요해서 보류

## 구현 메모
- 기록은 결과 화면이 뜨는 순간 저장 (창을 닫아도 유실 없음). [정원에 심기]는 정원으로 이동해 새 식물을 강조
- 1분 미만이면 정원에 기록하지 않음
- 진행 중 창이 닫히거나 새로고침되면, 마지막으로 확인된 시각까지로 처리 (보너스 중이었다면 성공 + 보너스)
- 10초 유예·5분 이어하기는 실제 시간 기준. 확인용 `?fast`(1분 = 1초)를 붙여도 그대로
