개인정보처리방침

'아 맞다 약!'(이하 '서비스')는 회원 가입이나 로그인 없이 쓰는 서비스예요. 이름 · 전화번호 · 이메일 같은 개인정보를 받지 않고, 적으신 내용은 이용자 휴대폰(브라우저) 안에만 저장돼요.

1. 운영자가 받는 개인정보

서비스 운영자는 이용자의 이름 · 연락처 같은 개인정보를 받지 않아요. 적으신 약 이름 · 먹은 기록 · 몸 상태는 운영자에게 보내지지 않아요. 다만 약 먹을 시각 알림을 켠 경우에만 알림을 보내는 데 필요한 정보를 서버에 저장해요. (아래 4번)

2. 이용자 휴대폰에 저장되는 정보

아래 내용은 서비스를 쓰기 위해 이용자 휴대폰의 브라우저 저장 공간에만 저장돼요. 약과 몸 상태는 건강에 관한 정보이니 휴대폰 화면 잠금을 꼭 켜 두세요.

3. 접속할 때 자동으로 처리되는 정보

서비스 화면을 휴대폰에 보내 드리는 과정에서 접속 주소(IP), 브라우저 종류, 접속 시각 같은 정보가 서비스를 맡아 전달하는 업체(Amazon Web Services)의 시스템에서 처리될 수 있어요. 이 정보는 화면 전달과 지나치게 많은 접속을 막는 보안 목적으로만 쓰이고, 운영자는 이것으로 이용자가 누구인지 알아보지 않아요.

4. 약 먹을 시각 알림을 켠 경우

알림은 이용자가 [먹는 시각] 화면에서 직접 켰을 때만 동작해요.

알림을 켰을 때 서버에 저장되는 정보

보관 기간알림을 끄면 바로 지워요. 앱을 90일 동안 열지 않으면 자동으로 지워져요.

알림은 휴대폰 회사의 알림 전달 서비스(구글, 애플 등)를 거쳐 전달돼요. 알림 내용은 암호화되어 전달 서비스가 읽을 수 없어요.

5. 약 목록 링크로 보낼 때

'약 목록 보내기'로 만든 링크에는 다음 내용이 담겨요.

  • 담기는 것: 약 이름, 먹는 때, 먹는 날 · 기간, 식사 전후, 간단 메모, 먹는 시각
  • 담기지 않는 것: 비고, 먹은 기록, 몸 상태 기록

링크 안의 정보는 서비스 서버로 보내지지 않아요. 다만 링크를 보낸 메신저(카카오톡 등)에는 대화 내용으로 남고, 링크를 가진 사람은 누구나 약 이름을 볼 수 있어요. 믿을 수 있는 가족에게만 보내 주세요.

6. 쿠키 · 분석 도구 · 광고

서비스는 쿠키, 방문 분석 도구, 광고를 쓰지 않아요.

7. 정보를 지우는 방법

  • 약 하나씩 지우기: [약 등록] 화면에서 약마다 [지우기]
  • 먹은 기록 · 몸 상태 모두 지우기: [지난 기록] 화면의 [기록 모두 지우기]
  • 알림 정보 지우기: [먹는 시각] 화면의 [알림 끄기] (서버에서 바로 지워져요)
  • 전부 지우기: 알림을 끈 뒤, 홈 화면 앱을 삭제하거나 브라우저 설정에서 이 사이트의 데이터를 삭제

휴대폰에서 지운 정보는 운영자도 되살릴 수 없어요.
