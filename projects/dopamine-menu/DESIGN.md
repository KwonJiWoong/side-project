# 딴짓 메뉴 디자인 가이드

딴짓 메뉴 화면을 고치거나 새 화면을 만들 때 따르는 기준입니다.
값은 모두 `css/common.css`(토큰)와 `css/style.css`(화면)에 들어 있고, 이 문서와 코드가 다르면 **코드를 기준으로 이 문서를 고칩니다.**

---

## 1. 방향

| 항목 | 내용 |
|---|---|
| 대상 | 스마트폰에 익숙한 세대. 쉬는 시간이나 자기 전에 습관처럼 숏폼을 여는 사람 |
| 한 줄 목표 | 숏폼 열기 전에 딱 1번 뽑고, 폰을 내려놓게 한다 |
| 느낌 | 심플한 앱. 흰 화면, 연회색 블록, 빨간 포인트 하나 |
| 흐름 | **고르기 → 하기 → 도장** 세 단계만. 그 밖의 단계·설정·장식은 넣지 않는다 |

**세 가지 원칙**

1. **덜어 낸다.** 넣을지 고민되면 뺀다. 그림자, 굵은 테두리, 무늬, 보조 설명 문구를 쓰지 않는다.
2. **할 일은 하나.** 한 화면에 빨간 버튼(핵심 동작)은 1개만 둔다.
3. **엄지로 편하게.** 누르는 것은 48px 이상, 핵심 버튼은 56px. 손이 닿는 아래쪽에 버튼을 모은다.

> 이 사이트는 노약자 전용이 아니다. 저장소 공통 규칙(CLAUDE.md의 시니어 원칙) 중 글자 18px, 글자 크기·고대비 설정 UI, "처음으로" 버튼은 적용하지 않는다. 대비 7:1, 키보드 사용, 움직임 줄이기 지원은 그대로 지킨다.

## 2. 색

색 토큰만 쓰고, 색상 코드는 `common.css`의 `:root`와 다크 모드 블록에만 쓴다.
다크 모드는 **기기 설정을 그대로 따른다**(`prefers-color-scheme`). 화면 안에 전환 버튼은 두지 않는다.

| 토큰 | 밝은 화면 | 어두운 화면 | 쓰는 곳 |
|---|---|---|---|
| `--color-bg` | `#ffffff` | `#121214` | 페이지 배경 |
| `--color-surface` | `#ffffff` | `#121214` | 탭 호버, 진행 막대 바탕 |
| `--color-soft` | `#f4f3f0` | `#232327` | 카드·탭 묶음·도장 칸·보조 버튼 바탕 |
| `--color-text` | `#18181b` (17.7:1) | `#f4f4f5` (17:1) | 본문, 제목 |
| `--color-text-sub` | `#45434a` (9.8:1) | `#b9b9c0` (9.6:1) | 설명, 날짜, 보조 정보 |
| `--color-primary` | `#a51d14` (7.5:1) | `#ff7a6b` (7.4:1) | 핵심 버튼, 선택된 탭, 타이머 숫자, 도장, "?" |
| `--color-on-primary` | `#ffffff` | `#1a0705` | 빨간 바탕 위 글자 (어두운 화면에선 어두운 글자) |
| `--color-line` | `#8a8580` | `#7a7a82` | 빈 도장 칸 점선 |
| `--color-divider` | line 40% 투명 | 같음 | 헤더·푸터·목록 구분선 |
| `--color-focus` | `#0b57d0` | `#8ab4f8` | 키보드 포커스 테두리 |

- **빨강은 "누를 것" 또는 "해낸 것"에만** 쓴다. 장식이나 제목 강조에 쓰지 않는다.
- 새 색을 추가하지 않는다. 필요하면 기존 토큰의 투명도(`color-mix`)로 만든다.
- 글자 대비는 7:1 이상, 테두리·아이콘은 3:1 이상.

## 3. 글자

- 글꼴: **Pretendard** (CDN), 없으면 Noto Sans KR → 시스템 고딕
- 기본 크기 16px(`html { font-size: 100% }`), 행간 1.6, 자간 -0.01em
- 굵기: 본문 400 · 강조 700 · 제목 800 (세 단계만)
- 큰 제목은 자간을 좁힌다(-0.02 ~ -0.03em)

| 역할 | 크기 | 굵기 | 예 |
|---|---|---|---|
| 메인 문구 | `clamp(1.625rem, 7.5vw, 2.25rem)` | 800 | 숏폼 열기 전에, 딱 1번만 뽑아 보세요 |
| 타이머 숫자 | `clamp(3.5rem, 18vw, 5rem)` | 800, 숫자 폭 고정 | 04:59 |
| 추천 카드 제목 | `clamp(1.375rem, 6vw, 1.75rem)` | 800 | 창문 열고 바깥 소리 3가지 찾기 |
| 섹션 제목 · 헤더 | 1.125rem | 800 | 얼마나 쉴까요? / 이번 주 도장판 |
| 버튼 | 1rem (핵심 버튼 1.0625rem) | 700 | 이걸로 할게요 |
| 본문 · 설명 | 1rem | 400 | 활동 설명 |
| 보조 정보 | 0.9375rem | 400~700 | 쉬기 · 5분, 끝나는 시각 |
| 작은 표시 | 0.8125 ~ 0.875rem | 400~800 | 광고 라벨, 도장 개수, 오늘 |

## 4. 크기 · 간격 · 모서리

| 토큰 / 값 | 크기 | 쓰는 곳 |
|---|---|---|
| `--touch` | 3rem (48px) | 모든 버튼·링크 최소 높이 |
| 핵심 버튼 높이 | 3.5rem (56px) | `.btn--primary` |
| `--radius` | 1rem | 버튼, 탭, 도장 칸 |
| `--radius-lg` | 1.5rem | 카드, 타이머 블록 |
| `--radius-pill` | 999px | 진행 막대 |
| `--page-pad` | `clamp(1rem, 5vw, 1.5rem)` | 화면 좌우 여백 |
| 본문 폭 | 32rem (태블릿 이상 36rem) | `.container` |
| 섹션 사이 | 3rem | 메뉴판 · 타이머 · 도장판 사이 |
| 요소 사이 | 0.75rem (버튼 사이), 0.375rem (탭 사이) | |

- 테두리는 거의 쓰지 않는다. **구분은 바탕색(soft)과 여백으로** 한다.
- 테두리를 쓰는 곳은 선택 상태(오늘 칸 `--border-w` 빨강)와 구분선(divider 1px)뿐이다.
- 그림자는 쓰지 않는다.

## 5. 화면 구성

위에서 아래로 한 줄 흐름이다. 화면을 넓혀도 가운데 한 열을 유지한다.

```
헤더 (로고 + 딴짓 메뉴, 위에 고정)
메인 문구
① 얼마나 쉴까요?   [5분][15분][30분]
   추천 카드 (앞면 ? / 뒷면 활동)
   [오늘의 추천 뽑기]  →  [이걸로 할게요] [다른 거 (남은 n회)]
② 타이머 (시작하면 ①을 숨기고 대신 보임)
   [다 했어요, 도장 찍기] [그만하기]
③ 이번 주 도장판 (월~일 7칸 + 이번 주에 한 일)
광고 (한 곳)
푸터 (개인정보 처리방침, ©)
```

## 6. 부품

### 헤더
- 화면 위에 붙어 있고(`sticky`), 배경은 90% 불투명 + 흐림 효과
- 로고(도장 아이콘) + "딴짓 메뉴"만. 메뉴·버튼을 넣지 않는다

### 버튼
| 종류 | 모양 | 규칙 |
|---|---|---|
| 핵심 (`.btn--primary`) | 빨강 바탕, 56px | 화면에 1개. 무엇이 일어나는지 쓴다 |
| 보조 (`.btn`) | soft 바탕, 테두리 없음, 48px | 바꾸기, 그만하기, 다시 시도 |
- 아이콘(20px)을 글자 앞에 둔다. 아이콘만 있는 버튼은 만들지 않는다
- 누르면 살짝 작아진다(`scale(0.98)`, 0.1초)

### 시간 탭
- soft 바탕 묶음 안에 세 칸. 선택된 칸은 빨강 바탕 + `✓`
- 글자는 숫자 + "분"만. 설명 문구를 붙이지 않는다
- 방향키·Home·End로 이동 (`role="tablist"`)

### 추천 카드
- soft 바탕, 큰 모서리, 그림자·테두리 없음
- 앞면: 빨간 "?" 하나만
- 뒷면: `종류 · 시간` → 제목 → 설명 한 문장, 가운데 정렬

### 타이머
- 활동 제목 → 설명 → 큰 숫자 → 진행 막대 → 끝나는 시각
- 시간이 다 되면 "시간이 다 됐어요. 잘하셨어요!"를 빨간 글자로 보여 준다

### 도장판
- 월~일 7칸, soft 바탕. 오늘 칸은 빨간 테두리 + "오늘" 글자
- 빈 칸은 점선 원, 찍은 칸은 기울어진(-12°) 빨간 도장 + 개수
- 아래에 "이번 주에 한 일" 목록 (요일 · 시간 + 활동 이름, 구분선)

### 안내 문구 (`.note`)
- soft 바탕 + 정보 아이콘. 경고일 때만 빨간 테두리(`.note--warn`)

## 7. 움직임

| 동작 | 효과 | 시간 |
|---|---|---|
| 뽑기 | 카드가 Y축으로 뒤집힘 | 0.6초 |
| 다른 거 | 카드가 한 바퀴 더 돎 | 0.6초 |
| 도장 찍기 | 도장이 크게 나타났다 제자리로 "쾅" | 0.35초 |
| 버튼 누름 | 살짝 작아짐 | 0.1초 |
| 색 변화(호버) | 바탕색만 바뀜 | 0.15초 |

- 움직임은 위 다섯 가지만. 자동으로 움직이거나 반복되는 효과는 넣지 않는다
- 기기에서 **움직임 줄이기**를 켜면 모든 효과를 끄고, 카드 뒤집기만 0.3초 페이드로 바꾼다

## 8. 아이콘

- 24×24 viewBox, 선 굵기 2.2 안팎(체크는 2.8), 끝 둥글게, 색은 `currentColor`
- HTML 위쪽 아이콘 모음(`<symbol>`)에 넣고 `<use>`로 쓴다. 이미지 파일로 따로 만들지 않는다
- 항상 글자와 함께 쓰고 `aria-hidden="true"`를 붙인다
- 도장(`#s-done`)은 64×64, 이중 원 + 체크. 로고·파비콘·도장판에 같이 쓴다

---

## 9. 문구

- **해요체, 짧게.** 한 문장에 한 가지만 말한다
- 버튼은 할 일을 쓴다: `오늘의 추천 뽑기`, `이걸로 할게요`, `다 했어요, 도장 찍기`
- 강요하지 않는다: "숏폼 그만 보세요" ✕ → "딱 1번만 뽑아 보세요" ○
- 막혔을 때는 다음 행동을 제안한다: "오늘은 이 메뉴로 해볼까요?"
- 활동 문장(`data/activities.json`)은 준비물 없이, 혼자, 안전하게, 한 문장으로

---

## 10. 광고

- 도장판 아래 **한 곳만**. 뽑기·타이머 버튼 근처에는 넣지 않는다 (잘못 누르기 쉬움)
- "광고" 라벨을 작게 붙이고, 광고가 늦게 떠도 화면이 밀리지 않게 자리를 미리 잡아 둔다
- 화면 아래 고정 광고·전면 광고(자동 광고)는 쓰지 않는다

---

## 11. 하지 않는 것

- 그림자, 굵은 테두리, 무늬·질감 배경
- 새 색 추가, 빨강을 장식으로 쓰기
- 글자 크기·고대비 설정 버튼, 메뉴 여러 개
- 보조 설명 문구 덧붙이기 (탭 설명, "몇 가지 준비돼 있어요" 같은 문구)
- 단계 늘리기 (확인 창, 중간 화면)
- 자동 재생·반복 애니메이션
